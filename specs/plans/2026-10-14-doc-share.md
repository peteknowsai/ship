# Doc share Implementation Plan

> **For agentic workers:** the ship driver dispatches each task to the engine `route.py` picks. Steps use checkbox (`- [ ]`) syntax. Never commit; never `git reset/checkout/stash`. End with STATUS, TESTS, CONCERNS.

**Goal:** A Share button on every ship doc in Pete's Chrome publishes the page to a public, unlisted, versioned link on `share.peteknowsai.xyz`; ship's redraws republish it, and the client flips back through versions from a footer.

**Architecture:** Three pieces with two seams. (1) `share/worker/`: a Cloudflare Worker + R2 bucket `ship-share` that stores versions and draws the footer at serve time. (2) `plugins/ship/skills/pipeline/scripts/share.py`: a stdlib Python CLI on Pete's Mac that bundles a local HTML file into one self-contained file, uploads it with a Keychain token, remembers which doc maps to which link, and doubles as the Chrome native messaging host. (3) `chrome/ship-tabs/`: the extension draws the button in a shadow root on doc tabs and talks to share.py through native messaging. `show.sh` calls `share.py republish` after every open.

**Tech Stack:** Cloudflare Workers (ES modules, R2 binding, wrangler), Python 3 stdlib only, Chrome MV3 extension (plain JS, no build), Node 26 for JS tests (no deps).

**Spec:** `specs/designs/2026-10-14-doc-share.html` (locked storyboard, round 2). Frame ids: `idle`, `hover`, `sharing`, `copied`, `redrawn`, `panel-v`, `error`, `client-a`, `client-old`, `client-phone`. Read a frame's markup and CSS in the `<template data-frame="…">` and the `BASE` style block at the top of each template: that CSS is the CSS to ship.

## Seams (exact contracts)

**HTTP API (Task 1 serves, Task 2 calls).** Base `SHIP_SHARE_URL`, default `https://share.peteknowsai.xyz`.
- `PUT /api/<id>?name=<name>` body = the bundled HTML (utf-8), header `authorization: Bearer <token>`. 200 JSON `{"url": "https://share.peteknowsai.xyz/<id>/<name>", "version": n, "versions": N, "changed": bool, "at": "<ISO of version n>"}`. Same bytes as the newest version → no new version, `changed:false`. 401 `{"error":"unauthorized"}`, 400 bad id/name, 413 over 20 MB.
- `DELETE /api/<id>` bearer. 200 `{"deleted": k}` (k objects removed, 0 if none).
- `GET /<id>/<name>[?v=n]` public. Unknown id (or unknown v): 404 page `This page isn't shared anymore.`

**Native messaging (Task 3 sends, Task 2 answers).** Host name `com.pete.ship.share`. One request per spawn (`chrome.runtime.sendNativeMessage`).
- Request `{"cmd": "status"|"publish"|"stop"|"copy", "key": "<key>", "file": "<abs path>"}` (`file` required for publish only).
- `publish` and `copy` put the URL on the clipboard; `status` and `stop` never touch it.
- Response success `{"ok": true, "shared": bool, "url": str|null, "version": int|null, "versions": int|null, "at": "<ISO>"|null}`; for `copy` the same shape after putting `url` on the clipboard. Failure `{"ok": false, "error": "<one human sentence>"}`.
- `key`: the extension's tag key: `repo/slug/kind` for storyboard/plan/review, the absolute file path for other docs (that is what `shipTag(href).key` already returns).

### Task 2: share.py, the bundler, uploader and native host

**Files:**
- Create: `plugins/ship/skills/pipeline/scripts/share.py`, `plugins/ship/skills/pipeline/scripts/share-host.sh`

**Runtime facts that bind this task:** Chrome spawns the host with Chrome's environment, not Pete's shell: PATH is minimal, so every external binary is called by absolute path (`/usr/bin/security`, `/usr/bin/pbcopy`). `share-host.sh` runs `/usr/bin/python3`, which is Python 3.9: no `match`, no `X | None` annotations, no 3.10+ stdlib. The host writes only framed JSON to stdout; anything else kills the connection.

**Interfaces:**
- Consumes: the HTTP API (Seams).
- Produces: the native messaging contract (Seams), and the CLI:
  - `share.py publish <key> <file>` → prints the response JSON, copies the URL (pbcopy).
  - `share.py republish <key> <file>` → if `key` was shared before, publish without touching the clipboard; otherwise exit 0 doing nothing. Never exits nonzero (show.sh runs it in the background).
  - `share.py stop <key>`, `share.py status <key>`, `share.py copy <key>`.
  - `share.py host` → native messaging: read one length-prefixed message from stdin, answer one, exit.
  - `share.py install <extension-id>... [--dir <NativeMessagingHosts dir>]` → writes `com.pete.ship.share.json` (`"type": "stdio"`, `"path"`: absolute path of `share-host.sh` beside the script, resolved; `"allowed_origins"`: one `chrome-extension://<id>/` per id given). Default dir `~/Library/Application Support/Google/Chrome/NativeMessagingHosts`.
  - `share.py --selftest`.
  - Python functions: `bundle(path: str) -> str`, `name_for(key: str, file: str) -> str`, `read_msg(stream) -> dict`, `write_msg(stream, obj)`, `handle(req: dict) -> dict`.
