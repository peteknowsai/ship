Ship with Astra

Codex now has a shorter ship workflow with direct Astra subagents. Small fixes stay with the driver. Design approval stays where it changes what gets built.

RequestProcess
ExpressWorktree, fix, check, land. No cards.
Self-directedPlan only as needed. Parallel independent work. Review and prove.
DesignLive storyboard, design lock, plan card, go, then build.
NextTriage the board. Ship whole cards sequentially.

Independent build tasks run in parallel. A fresh code reviewer and runtime verifier can inspect the same frozen build concurrently. Tests repeat only when changes invalidate their evidence.

No supervisors, nested coding sessions, or app-server dispatcher. The package reuses the Claude workflow's HTML templates, while its instructions use Codex tools.

Checks for future updates
  • A one-file express fix does not acquire design gates.
  • Design waits for both lock and go.
  • Next processes ships sequentially and explains a missing board.
  • A repository's land command overrides PR mechanics.
  • Existing Codex worktrees remain owned by the app.
  • Workers own separate files and preserve others' edits.
  • Broken or unreachable behavior cannot pass verification.
  • Runtime verification never substitutes a mockup for evidence.
  • Existing authorization is preserved; unapproved releases still gate.
  • The portable package contains both native skills and all referenced templates.
