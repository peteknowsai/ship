For the record
  • How it works: the Ship tabs extension draws the button and hands the file to a small script on your Mac (Chrome native messaging, the same way your existing handoff host works). The script reads the page and everything it links from disk, inlines it into one file, and uploads it with a key from your Keychain to a ship-share Worker and R2 bucket on your PKAI Cloudflare account, at share.peteknowsai.xyz.
  • One stable id per doc (app, ship and kind), random so links can't be guessed; every page is marked noindex. No expiry, no password (your call).
  • Redraws: show.sh republishes a doc that has been shared before, so the link follows each round without the extension.
  • Reuse audit: nothing in the ship repo shares or hosts pages today; the board Worker (board.cells.md) is the pattern to copy. peteknowsai.xyz is active on PKAI with nothing at the apex, which stays free for a consulting site.
  • Consults: none. No installed expert covers native messaging; the Cloudflare side repeats the board's setup.
